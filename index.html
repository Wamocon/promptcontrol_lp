Häufige Fragen

Alles, was Sie wissen müssen.

Ein System-Prompt definiert das Verhalten eines KI-Modells in Ihrem Produkt. Ohne zentrale Verwaltung liegen diese Prompts als Strings direkt im Quellcode verteilt – jede Änderung erfordert einen Deployment-Zyklus. ProCon entkoppelt Prompt-Änderungen vom Code-Deploy.
Ihre Applikation sendet einen GET-Request mit dem Prompt-Slug und einem API-Schlüssel an ProCons REST-Endpoint. ProCon antwortet mit dem aktuell aktiven Prompt-Text. Wechseln Sie zur neuen Version im Dashboard – Ihre Applikation erhält sie beim nächsten Request automatisch.
Der Compliance-Scanner erkennt automatisch DSGVO-kritische Formulierungen und Muster für persönliche Identifikationsdaten (PII). Er gibt eine Warnung aus, bevor ein Prompt aktiviert wird.
ProCon stellt einen MCP-Server (Model Context Protocol) bereit. Verbinden Sie GitHub Copilot oder eine andere MCP-kompatible IDE damit – alle Unternehmens-Prompts stehen dem KI-Assistenten direkt zur Verfügung.
ProCon basiert auf Next.js 16 (App Router), TypeScript, Tailwind CSS v4 und Supabase (PostgreSQL). Deployment auf Vercel. Der gesamte Tech-Stack ist im öffentlichen Repository dokumentiert.
