REST-API — Prompts direkt einbinden

Prompts per API abrufen.

Binden Sie ProCon-Prompts direkt in Ihre Anwendung ein. Die REST-API gibt versionierte, freigegebene Prompts in Millisekunden zurück.

ProCon REST API
# GET /api/prompts/customer-service?version=latest
curl -H "Authorization: Bearer YOUR_API_KEY" \
https://api.procon.app/v1/prompts/customer-service
# Response (200 OK · 42ms)
{
"id": "customer-service",
"version": 3,
"status": "approved",
"content": "Du bist ein freundlicher Kundenservice-Assistent...",
"compliance_score": 98,
"approved_by": "team-lead@company.com"
}
